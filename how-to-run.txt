MALAY-SHUTTLE

Run these commands in PowerShell from the folder containing pom.xml.

$env:SHUTTLE_DRIVER_CODE = "replace-with-a-private-driver-code"
.\mvnw.cmd clean spring-boot:run

Open http://localhost:8080. Java 21 is required.

For a two-device demo, connect both devices to the same network and open
http://HOST_IP:8080 on the second device. Use sample names on plain HTTP.

The passenger opens Pickup ping, chooses a stop, types a name, and sends a ping.
The driver opens Driver controls under Shuttle status and enters the driver code.
The driver can update the occupied count, view incoming alerts, and dismiss them.
