Step 1: Open your project in VS Code
Open this folder:
C:\Users\King\Desktop\malay-shuttle\malay-shuttle


Then open a terminal using Terminal → New Terminal.
Step 2: Set your MySQL password
In Terminal 1, enter:
$env:DB_PASSWORD = "king0609"


Replace the placeholder with your actual malay_app password.

Make sure your MySQL Server service is running.
Step 3: Start Spring Boot
In the same terminal, run:
.\mvnw.cmd spring-boot:run


Your website should now be accessible at:
http://localhost:8080 | Keep Terminal 1 running!
Step 4: Open a second terminal
In VS Code:
1. Click Terminal → New Terminal.
2. Leave Terminal 1 running.
3. In Terminal 2, enter:
cloudflared tunnel --url http://localhost:8080


If cloudflared isn't recognized, restart VS Code or use the full path to cloudflared.exe.
